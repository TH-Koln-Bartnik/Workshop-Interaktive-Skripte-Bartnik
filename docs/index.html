Ziele des Workshops

Am Ende des Workshops können Sie …

  1. in einer fertig eingerichteten Vorlage eine interaktive Lehreinheit bauen: vom Vorab-Check über Lernspiele bis zum Lern-Check,
  2. Interaktionstypen begründet auswählen, gestützt auf die Lernforschung,
  3. KI als Hilfskraft einsetzen: Grundbegriffe sammeln, Lernspiele programmieren, den Rahmen der Einheit entwerfen lassen und die Ergebnisse prüfen,
  4. eigene Texte, Bilder und Zotero-Quellen in die Struktur einbauen,
  5. die Einheit auf dem eigenen Rechner rendern und auf Wunsch veröffentlichen.

Im Workshop bauen Sie eine eigene interaktive Lehreinheit, und zwar vom ersten Block an mit KI: Sie arbeiten in einer Vorlage, in der Ordner, Platzhalter für Bilder und Spiele und der Rahmen der Einheit schon angelegt sind. Die KI programmiert die Lernspiele, Sie entscheiden über Inhalte und Didaktik. Damit die gemeinsame Zeit dem Bauen gehört und nicht dem Installieren, richten Sie die Werkzeuge vorher zu Hause ein. Wie das geht, steht in Teil 0.

Der Workflow auf einen Blick

Die Animation zeigt, welches Werkzeug welche Aufgabe übernimmt und in welcher Phase es dazukommt. Mit „▶ Start“ oben rechts oder der Leiste unten gehen Sie durch die sechs Schritte; die Pfeiltasten funktionieren, sobald Sie einmal in die Animation geklickt haben. Ein Klick auf ein Werkzeug öffnet eine kurze Erklärung. In Schritt 0 können Sie Ihre Installationen abhaken.

Ablauf

Der Workshop beginnt mit einem Lernspiel, das nach 45 Minuten in Ihrer eigenen Lehreinheit läuft, und arbeitet sich von dort zur ganzen Einheit vor. Die KI übernimmt von Anfang an das Programmieren; Code von Hand schreiben Sie nicht. Alles läuft zunächst auf Ihrem eigenen Rechner. Die Dauern sind Richtwerte ohne Pausen.

Teil Dauer Inhalt Kapitel
Teil 0 — Vorbereitung zu Hause ca. 2–3 h, vor dem Workshop Werkzeuge installieren, Starter-Vorlage einmal rendern (Selbsttest), Rohmaterial sammeln 0, Galerie, Best Practice
Block 1 — Das erste Spiel 45 min Vorlage öffnen, Grundbegriffe per Multiple Choice sammeln, Memory bauen lassen und einbauen im Workshop
Block 2 — Was wirkt? 20 min Fünf Prinzipien und eine Palette von Interaktionstypen; KI schlägt passende Interaktionen vor im Workshop
Block 3 — Zwei Interaktionen 45 min Konzeptkarte, zwei weitere Spiele bauen lassen, wie eine Studentin testen im Workshop
Block 4 — Die Einheit rahmen 45 min Szene, Vorab-Check, Lernziele, Kernaussagen und Lernfragen per KI im Workshop
Block 5 — Feinschliff 90 min eigene Texte, Bilder tauschen, Zotero-Quellen, KI als kritische Erstleserin im Workshop
Block 6 — Rundgang 30–45 min Einheiten gegenseitig testen, optional veröffentlichen im Workshop
Werkzeugkasten zum Nachschlagen Grundlagen und Vertiefungen: Setup, Bilder, Zotero, Hochschulstil, Diagramme, iFrames und Tutor, Widgets, GitHub Pages, Slides folgt
Kür — nach dem Workshop nach Bedarf einen Kurs mit einem KI-Agenten bauen; öffentliches und internes Material trennen; das Skript in ILIAS oder Moodle einbinden folgt

Jeder Prompt steht in zwei Fassungen: für einen Chat (ChatGPT, Claude, Gemini, Academiccloud), aus dem Sie die Antwort kopieren, und für einen Agenten (Claude Desktop, Codex), der die Dateien selbst in Ihren Ordner schreibt.

Kein eigenes Thema? Wählen Sie einen Beispielstrang

Am meisten lohnt sich der Workshop mit einem Thema aus Ihrer eigenen Lehre. Wer keines mitbringt, nutzt ein durchgehendes Mini-Thema: eine kurze Einführung ins wissenschaftliche Arbeiten. Wählen Sie einen der drei Stränge, oder bringen Sie eigenes Material mit (siehe Mitbringliste).

Strang Worum es geht Quelle
A — Wissenschaftliche Einstellung Skepsis, Belege, intellektuelle Demut Bartnik & Palmer (2024), Kap. „Wissenschaftliche Einstellung“
B — Recherche und Quellenqualität Suchen, prüfen, Quellen einordnen Bartnik & Palmer (2024), Kap. „Kritische Informationssuche“
C — Transparent schreiben Methoden offenlegen, Reproduzierbarkeit Bartnik & Palmer (2024), Kap. „Transparent schreiben“

Die technischen Schritte sind in jedem Strang identisch.

Wie Sie dieses Skript benutzen

Jeder Block und jedes Kapitel öffnet mit einem Lernziel-Kasten („Was Sie nach diesem Block können“), gefolgt von der eigentlichen Übung. Dazwischen steht so wenig Text wie möglich. Am Ende jedes Kapitels finden Sie einen Kasten „Was, wenn …“ mit den häufigsten Stolpersteinen und einen fertigen Tutor-Prompt zum Kopieren. Die Lernziele und Übungen sind aufeinander abgestimmt, wie es Constructive Alignment verlangt (Biggs & Tang, 2011); die interaktiven Elemente haben einen lerntheoretischen Grund, keinen dekorativen (Mayer, 2021).
