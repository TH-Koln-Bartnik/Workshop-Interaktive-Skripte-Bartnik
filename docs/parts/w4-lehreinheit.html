Block 4 — Die Einheit rahmen: vom Vorab-Check zu den Lernfragen

45 Minuten · Szene, Einschätzungen, Lernziele, Kernaussagen und Lernfragen per KI

Was Sie nach diesem Block können

  • erklären, warum eine Lehreinheit mit einem Vorab-Check beginnt und mit einem Lern-Check endet;
  • Szene, Vorab-Check, Lernziele, Auflösungen, Kernaussagen und Lernfragen von der KI im Quarto-Format entwerfen lassen;
  • die Entwürfe in die feste Struktur der Vorlage einfügen, ohne die Technik zu beschädigen.

Worum es im Kern geht

Ihre Spiele stehen. Jetzt bekommt die Einheit ihren Rahmen. Die Vorlage folgt dem Aufbau der Kapitel im Lehrbuch Generative KI als Hilfe zum Lehren und Lernen (Bartnik, 2025): Eine Szene stellt ein offenes Problem, ein Vorab-Check legt die Lernenden auf eine Meinung fest, im Text wird jede Aussage aufgelöst, und am Ende prüfen Lern-Check, Kernaussagen und Lernfragen, was hängen geblieben ist.

Warum diese Reihenfolge?

Die Lernfragen am Ende folgen drei Stufen: Wiederholen fragt nach dem Stoff, Anwenden nach einem neuen Fall, Beurteilen nach einer Abwägung. So wächst der Anspruch von der Erinnerung zum Urteil.

Mach mit — die KI entwirft den Rahmen (20 min)

  • Chat (jede KI)
  • Agent (Claude Desktop, Codex)

Fügen Sie Ihr Rohmaterial in den Prompt ein. Die Antwort enthält fertige Quarto-Blöcke; Sie kopieren sie in lehreinheit.qmd an die Stelle des passenden gelben ERSETZEN-Kastens.

Ich baue eine Lehreinheit in Quarto. Thema: [ … ]. Niveau: [ … ]. Die drei Abschnitte heißen: [ 1 … / 2 … / 3 … ].
Hier ist mein Rohmaterial (Text, Stichpunkte oder Folien): [ einfügen ]

Schreiben Sie mir in genau dieser Quarto-Syntax (Muster siehe unten):
1. eine Szene aus dem Fach in vier bis fünf Sätzen: eine Person, eine konkrete Situation, ein offenes Problem;
2. drei Aussagen für den Vorab-Check (Kennungen ez-1 bis ez-3), je eine zu einer typischen Fehlvorstellung pro Abschnitt, so formuliert, dass man zustimmen oder widersprechen kann;
3. drei Lernziele mit beobachtbaren Verben;
4. zu jeder Aussage den Prüfkasten „Ihre Einschätzung prüfen“ mit Auflösung in zwei Sätzen;
5. drei Kernaussagen, je eine pro Lernziel;
6. Lernfragen in drei Stufen: Wiederholen, Anwenden, Beurteilen (je ein bis zwei Fragen).

Erfinden Sie keine Studien oder Zahlen. Wo eine Quelle nötig wäre, schreiben Sie [QUELLE?].

Muster:
```
## Titel des Abschnitts {#sec-abschnitt-1}

::: {.einschaetzung #ez-1}
Aussage, der man zustimmen oder widersprechen kann.

[Auflösung im ersten Abschnitt](#sec-abschnitt-1){.ez-verweis}
:::

::: {.callout-tip .ez-pruefen title="Ihre Einschätzung prüfen"}
*„Aussage wörtlich wiederholt“* []{.ez-ihre data-ez="ez-1"}

**Auflösung: ja/nein/teils.** Begründung in zwei Sätzen.
:::
```

Der Agent ersetzt die Blöcke direkt in lehreinheit.qmd und lässt Ihre Abschnittstexte stehen.

Öffnen Sie lehreinheit.qmd. Mein Thema: [ … ]. Niveau: [ … ]. Mein Rohmaterial liegt in material/ [ Dateiname ].

Ersetzen Sie die Beispielinhalte überall dort, wo ein gelber Kasten „ERSETZEN“ steht: Titel, Szene, die drei Aussagen des Vorab-Checks, Lernziele, die drei Prüfkästen „Ihre Einschätzung prüfen“, Kernaussagen und Lernfragen. Die Abschnittstexte selbst lassen Sie stehen; die schreibe ich.

Regeln:
- Kennungen (#ez-1 bis #ez-3, #sec-abschnitt-1 bis 3, #fig-abb-01 bis 03) und alle iframe-Zeilen bleiben unverändert.
- Löschen Sie jeden gelben ERSETZEN-Kasten, dessen Block Sie erledigt haben.
- Erfinden Sie keine Studien oder Zahlen; wo eine Quelle nötig wäre, schreiben Sie [QUELLE?].
- Rendern Sie danach mit `quarto render` und nennen Sie mir die Stellen, an denen ich nachbessern sollte.

Die drei Regeln beim Einfügen (Chat-Weg)

  1. Kennungen bleiben. #ez-1 in der Aussage und data-ez="ez-1" im Prüfkasten gehören zusammen wie Schlüssel und Schloss. Stimmen sie nicht überein, zeigt der Prüfkasten „Sie haben vorab keine Einschätzung abgegeben“.
  2. iFrame-Zeilen bleiben. Die Zeilen mit <iframe … src="interactions/spiel-0…"> fassen Sie nicht an.
  3. Gelbe Kästen weg. Löschen Sie jeden ::: ersetzen-Block samt seinen beiden :::-Zeilen, sobald Sie ihn erledigt haben. Was gelb bleibt, ist noch offen.

Prüfen (10 min)

Klicken Sie im Browser im Vorab-Check eine Einschätzung an und scrollen Sie zum passenden Prüfkasten: Dort muss Ihre Wahl wieder erscheinen. Dann lesen Sie Szene und Aussagen mit der Frage: Würde eine Studentin hier wirklich zögern? Eine Aussage, der alle sofort zustimmen, verschenkt den Vortest-Effekt. Jede Stelle, an der die KI [QUELLE?] geschrieben hat, belegen Sie in Block 5 mit einer echten Quelle oder streichen den Satz.

Was, wenn …

WarnungWas, wenn …
  • die Skala im Vorab-Check fehlt? → Die Aussage steht nicht in einem Block ::: {.einschaetzung #ez-…} oder der Block ist nicht mit ::: geschlossen. Doppelpunkte zählen: Jeder öffnende Block braucht einen schließenden.
  • nach dem Einfügen die halbe Seite fehlt? → Ein ::: zu wenig. Die KI fragen: „Hier ist meine lehreinheit.qmd. Finden Sie den nicht geschlossenen Block.“
  • die Szene klingt nach Werbetext? → „Schreiben Sie die Szene nüchtern, mit einer konkreten Person, einer Zahl und einem offenen Problem, ohne Adjektive wie spannend oder faszinierend.“
