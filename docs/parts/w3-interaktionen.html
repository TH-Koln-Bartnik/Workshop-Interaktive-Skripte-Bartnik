Block 3 — Fünf Ideen, zwei Interaktionen

45 Minuten · auswählen, Konzeptkarte, bauen lassen, testen

Was Sie nach diesem Block können

  • für ein Lernziel Ihrer Einheit eine passende Interaktion auswählen und begründen;
  • eine Konzeptkarte ausfüllen, die der KI sagt, was die Interaktion leisten soll;
  • das Ergebnis der KI gegen didaktische und technische Kriterien prüfen.

Worum es im Kern geht

Das Memory aus Block 1 übt Begriffe. Die meisten Lernziele verlangen mehr: Zusammenhänge erkennen, Fälle einordnen, Ergebnisse vorhersagen. Dafür wählen Sie jetzt zwei Interaktionen aus der Palette in Block 2 und lassen sie bauen. Die KI programmiert, Sie entscheiden, was die Lernenden tun und welche Fehlvorstellung sichtbar werden soll. Interaktionen, bei denen Lernende etwas erzeugen oder begründen, fördern das Lernen stärker als bloßes Klicken (Chi & Wylie, 2014).

Schritt 1 — Vorschläge holen (10 min)

Haben Sie den Auswahl-Prompt in Block 2 schon genutzt, nehmen Sie Ihre zwei Favoriten. Sonst jetzt:

Lesen Sie zuerst diese Zusammenfassung der Forschung zu Interaktionstypen und stützen Sie Ihre Vorschläge darauf: https://th-koln-bartnik.github.io/Workshop-Interaktive-Skripte-Bartnik/downloads/interaktionstypen-forschung.md
Falls Sie die Seite nicht öffnen können, sagen Sie es; dann füge ich den Text ein.

Meine Lehreinheit:
- Fach und Thema: [ … ]
- Lernziel dieser Einheit: [ … ]
- Eine typische Fehlvorstellung der Studierenden: [ … ]
- Niveau: [ erstes Semester / Bachelor / Master / Weiterbildung ]

Schlagen Sie mir fünf Interaktionen vor, die sich gut in ein Quarto-Skript einbauen lassen. Für jede:
1. Typ aus der Palette der Zusammenfassung;
2. konkrete Umsetzung zu meinem Thema in zwei Sätzen;
3. welches Lernprinzip sie nutzt, mit der Quelle aus der Zusammenfassung;
4. Einbauweg: Quarto-Kasten ohne Code, eigene HTML-Datei per iframe, H5P-Inhalt oder fremde Simulation;
5. Aufwand: klein, mittel oder groß.

Bevorzugen Sie Interaktionen, bei denen Lernende etwas erzeugen (vorhersagen, begründen, zuordnen mit Begründung), vor bloßem Klicken. Mindestens eine Option kommt ohne Programmierung aus. Sagen Sie offen, wenn eine Idee vor allem Dekoration wäre.
Fragen Sie mich am Ende per Multiple Choice, welche zwei Interaktionen ich umsetzen will.

Schritt 2 — Die Konzeptkarte (10 min)

Eine Konzeptkarte ist der Bauplan in sechs Zeilen. Sie zwingt zu der Entscheidung, die keine KI für Sie treffen kann: Welchen Denkfehler sollen Ihre Studierenden an dieser Stelle machen dürfen, damit die Rückmeldung ihn auflöst?

Rückmeldungen, die erklären, warum eine Antwort stimmt, wirken deutlich stärker als ein bloßes „richtig“ oder „falsch“ (Van der Kleij et al., 2015). Das Feld Rückmeldung ist deshalb das wichtigste der Karte.

Schritt 3 — Bauen lassen und einbauen (15 min)

Die Vorlage hat zwei weitere Plätze: spiel-02.html im zweiten Abschnitt und spiel-03.html als Lern-Check am Ende. Ihre erste neue Interaktion kommt auf Platz 2. Passt die zweite eher als Abschlussübung, kommt sie auf Platz 3; sonst ergänzen Sie einen weiteren Platz (siehe Variieren Sie).

  • Chat (jede KI)
  • Agent (Claude Desktop, Codex)

Die Konzeptkarte in die eckigen Klammern übertragen. Den Code danach wie in Block 1, Schritt 3 in interactions/spiel-02.html einfügen.

Bauen Sie die Interaktion, die wir ausgewählt haben, nach dieser Konzeptkarte:
- Lernziel: [ … ]
- Fehlvorstellung, die sichtbar werden soll: [ … ]
- Interaktionstyp: [ z. B. Vorhersage mit Auflösung, Zuordnen mit Begründung, Sortieren, Fehler finden, Lückentext ]
- Was die Lernenden tun: [ … ]
- Rückmeldung: [ was nach jeder Antwort erklärt wird ]
- Inhalte: [ Fragen, Begriffe oder Werte, oder: „Entwerfen Sie die Inhalte selbst und zeigen Sie sie mir zuerst als Tabelle.“ ]

Technische Abnahmekriterien:
- Eine einzige HTML-Datei, kein externer Code, keine Bilder oder Schriften aus dem Netz. Sie muss offline und eingebettet in einem iframe laufen.
- Alle Inhalte stehen oben in einem Block `const DATEN = { … };` zwischen den Kommentaren /* ===== DATEN: Nur diesen Block ändern ===== */ und /* ===== ENDE DATEN ===== */. Der Programmcode darunter liest nur aus DATEN.
- Alles Klickbare ist ein <button> und mit der Tastatur bedienbar; Rückmeldungen stehen in einem Bereich mit aria-live="polite".
- Auf einem Handy (360 px Breite) gut bedienbar, ohne seitliches Scrollen.
- Die Datei meldet ihre Höhe an die einbettende Seite: window.parent.postMessage({typ: "iframe-hoehe", hoehe: document.documentElement.scrollHeight}, "*") nach dem Laden, bei Größenänderung und nach jeder Antwort.
- Oberfläche auf Deutsch in der Sie-Form, sachlich, ohne Konfetti, Sounds oder dekorative Animationen.
- Jede Rückmeldung erklärt in einem Satz, warum eine Antwort stimmt oder nicht.

Geben Sie nur den vollständigen Code in einem einzigen Codeblock aus.

Arbeitsschritte:
1. Speichern Sie das Spiel als interactions/spiel-02.html (bzw. spiel-03.html, wenn ich das sage).
2. Passen Sie in lehreinheit.qmd nur Titel und Einleitungssatz des zugehörigen Lernspiel-Kastens an.
3. Rendern Sie mit `quarto render` und melden Sie Fehler in einfachen Worten.
Ändern Sie keine anderen Dateien.

Ohne Code: Vorhersage als aufklappbarer Kasten

Manche Interaktionen brauchen gar kein Spiel. Eine Vorhersage mit Auflösung schreiben Sie direkt in lehreinheit.qmd; Quarto macht daraus einen Kasten, der sich erst auf Klick öffnet:

**Ihre Vorhersage:** Ein Betrieb verdoppelt seine Produktionsmenge.
Was passiert mit den Stückkosten? Legen Sie sich fest, bevor Sie aufklappen.

::: {.callout-tip collapse="true" title="Auflösung"}
Sie sinken, weil sich die Fixkosten auf mehr Stück verteilen.
:::

Schritt 4 — Testen wie eine Studentin (10 min)

Spielen Sie Ihre Interaktion zweimal: einmal richtig, einmal absichtlich falsch. Dann tauschen Sie mit Ihrer Nachbarin und testen deren Spiel.

Die letzte Frage ist kein Geschmacksurteil. Interessante, aber irrelevante Zutaten lenken nachweislich ab und senken das Behalten (Rey, 2012).

Variieren Sie

  • Einen vierten Platz anlegen: In lehreinheit.qmd einen Lernspiel-Kasten kopieren und spiel-02.html durch spiel-04.html ersetzen. Dann der KI sagen, sie soll unter diesem Namen speichern.
  • Schwierigkeit staffeln: „Bauen Sie zwei Stufen: Stufe 1 mit Hinweisen, Stufe 2 ohne.“
  • Fremde Simulation statt eigenem Spiel: Für Physik und Mathematik einen PhET-Link als iFrame einbauen, mit einer Vorhersagefrage davor (Kapitel 7).

Was, wenn …

WarnungWas, wenn …
  • die KI eine Datei mit mehreren Teilen (HTML, CSS, JS) liefert? → „Bitte alles in eine einzige HTML-Datei, wie in den Abnahmekriterien.“
  • das Spiel Inhalte aus dem Netz nachlädt? → Im Lehrraum ohne WLAN bleibt es dann leer. Nachschieben: „Ohne externe Bibliotheken und Schriften.“
  • Ihnen das Ergebnis didaktisch nicht gefällt? → Nicht neu anfangen, sondern gezielt ändern lassen: „Die Rückmeldung bei Antwort B soll den Denkfehler benennen, nicht nur die richtige Lösung.“
